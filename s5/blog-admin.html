Blog editor for your own content

Write your blog posts here, save them as drafts, and publish them to the live blog page. This editor is designed for your current static website, so it stores posts in this browser and also lets you export or import your content as a JSON backup.

Draft + PublishExport / ImportNo backend required

Create or update a post

Use plain text with simple formatting. Blank lines create paragraphs. Start a line with ## or ### for headings, and use - for bullet lists.

URL format: blog.html?slug=your-post

Storage notes

This editor saves posts in this browser.
If you clear browser storage or open the site on another device, the posts will not be there unless you export them and import them again.
